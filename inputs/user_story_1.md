# User Story CP TestForge
1. Sebagai peserta lomba, saya menempelkan soal dan mendapat paket test
   (edge case, jebakan, stress) karena sample soal hanya 1-3.
2. Sebagai peserta lomba, saya menjalankan kode saya terhadap test itu dan
   melihat test mana yang WA/TLE/RE.
3. Sebagai peserta lomba, saya ingin expected output berasal dari eksekusi
   kode (brute force), bukan tebakan AI.
4. Sebagai peserta lomba, saya ingin bukti bahwa test dapat menangkap
   solusi salah dan solusi lambat.
Soal yang diuji: Maximum Subarray, Coin Change, Shortest Path, LIS,
Penukaran Emas, Diskon Beli A Gratis B.
