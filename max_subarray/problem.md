# Maximum Subarray Sum

## Deskripsi

Diberikan array N bilangan bulat. Cari jumlah terbesar dari subarray kontigu (minimal 1 elemen).

## Input

- Baris 1: N
- Baris 2: N bilangan A[1..N]

## Output

Satu bilangan: jumlah subarray terbesar.

## Constraints

- 1 ≤ N ≤ 100.000
- −1.000.000.000 ≤ A[i] ≤ 1.000.000.000
- Batas waktu: 1 detik

## Contoh Input

```
5
1 -2 3 4 -1
```

## Contoh Output

```
7
```

## Penjelasan

Subarray terbaik adalah `[3, 4]` dengan jumlah 7.
